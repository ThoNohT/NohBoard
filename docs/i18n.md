# 国际化（i18n）与界面翻译

NohBoard 的界面支持英文（源语言，回退语言）和简体中文。默认跟随 Windows 系统语言：中文系统显示中文，
其他系统显示英文；用户也可以在“设置”里手动选择语言（重启后生效）。

## 设计

界面文本的翻译采用“英文原文即 key”的方式：

- WinForms 设计器（`*.Designer.cs`）里的英文 `Text` 同时是翻译 key。
- 在窗体构造完成后调用 `Loc.Apply(this)`，会递归遍历该窗体及其所有子控件（包括 `ToolStrip` /
  `ContextMenuStrip` 菜单项），把已知的英文文本替换为当前语言的翻译；未知文本保持不变。
- 运行时拼接出来的文本（MessageBox、ToolTip、动态菜单项、文件对话框 Filter、DataGridView 列头等）
  在赋值处调用 `Loc.T(...)` 或 `Loc.Format(...)` 翻译。
- 缺失翻译时会原样显示英文，因此漏翻译不会导致界面损坏或崩溃。

相关文件：

| 文件 | 作用 |
| --- | --- |
| `NohBoard/NohBoard/Localization/Loc.cs` | `UiLanguage` 枚举、语言初始化、`T` / `Format` / `Apply` |
| `NohBoard/NohBoard/Localization/Loc.ChineseSimplified.cs` | 简体中文词典（key → 译文） |
| `NohBoard/NohBoard/Extra/GlobalSettings.cs` | `[DataMember] UiLanguage Language`，持久化到 `NohBoard.json` |
| `NohBoard/NohBoard/Forms/SettingsForm.*` | “语言”下拉框 |

### 语言枚举

```csharp
public enum UiLanguage
{
    Auto = 0,                 // 跟随系统（默认）
    English = 1,              // 英文
    ChineseSimplified = 2,    // 简体中文
}
```

`Loc.Initialize(UiLanguage)` 在 `MainForm_Load` 里、读取完 `NohBoard.json` 之后调用一次：

```csharp
var settingsLoaded = GlobalSettings.Load();
Loc.Initialize(GlobalSettings.Settings.Language);
Loc.Apply(this);
Loc.Apply(this.MainMenu);
```

`Auto` 的判定规则：系统 UI 语言是 `zh`（且不是繁体：台湾/香港/Hant）时用简体中文，其余用英文。

## 运行时切换

“设置 → 语言”下拉框提供“自动（跟随系统）/ 英文 / 简体中文”。保存后立即写入 `NohBoard.json` 的
`Language` 字段，并弹窗提示“语言更改将在重启 NohBoard 后生效”。由于所有窗体在构造时应用翻译，
切换语言需要重启进程才会全面生效。

也可以直接编辑 `NohBoard.json`：

```json
{
  "Language": 2
}
```

（`0` = 自动，`1` = 英文，`2` = 简体中文；旧版本设置文件缺少该字段时按 `0` 处理。）

## 测试用环境变量

为方便自动化测试和临时对照，可以在启动前设置环境变量覆盖设置文件里的语言：

```powershell
$env:NOHBOARD_UI_LANGUAGE = 'en'   # 强制英文
$env:NOHBOARD_UI_LANGUAGE = 'zh'   # 强制简体中文
$env:NOHBOARD_UI_LANGUAGE = 'auto' # 跟随系统
```

该变量优先级高于 `NohBoard.json`，只影响当前进程，不会写回设置文件。

## 新增/修改界面文本的约定

1. 在设计器里照常写英文文本，不需要额外改动；在 `Loc.ChineseSimplified.cs` 里增加一条
   `{ "English text", "中文译文" }`。
2. key 必须与代码中的英文字符串**完全一致**，包括末尾空格和换行符。多行文本在词典里用 `\r\n`
   表示（Windows）。例如设置界面里的多行 ToolTip：

   ```csharp
   { "Show capitalized letter when shift or caps is pressed, \r\nbut normal letters when both or neither are pressed.",
     "按下 Shift 或 Caps Lock 时显示大写字母，\r\n两者同时按下或都不按下时显示普通字母。" },
   ```

3. 菜单文本里的 `&` 是快捷键标记（助记符），翻译时可以移动到合适的中文字符前，例如
   `"&Settings"` → `"设置(&S)"`。
4. 运行时才生成的文本不能靠 `Loc.Apply` 覆盖，必须改代码：

   ```csharp
   this.mnuSaveDefinitionAsName.Text =
       Loc.Format("Save &To '{0}/{1}'", category, name);
   ```

5. 子控件/自定义控件里的文本如果是在设计器里赋值的，父窗体的 `Loc.Apply(this)` 会递归覆盖，不需要
   额外处理；只有在运行时动态赋值的文本才需要 `Loc.T`。
6. 专有名词（`NohBoard`、`kb` 文件扩展名、`Caps Lock`、`Shift` 等键名）可以保留英文。

## 已翻译范围

除透明窗口/打包等文档里另有说明的内容外，所有用户可见界面均已翻译：

- 主窗口右键菜单（含 F1 透明、F2 无边框、以管理员身份重启等运行时插入的菜单项），以及运行时拼接的
  “保存到 `类别/名称`”“发现新版本”等动态文本；
- 设置窗口（主设置页 + 语言选择 + 全部 ToolTip）；
- 加载键盘窗口、保存键盘定义/样式窗口、无边框矩形窗口、元素/键盘属性窗口、按键/键盘/鼠标速度样式窗口；
- 所有 MessageBox 正文与标题、文件对话框 Filter、缺失字体列表的 DataGridView 列头；
- 崩溃处理器（CrashHandler）的提示信息。

以下内容保持英文（有意不翻译）：

- 窗口标题中的产品名与版本号（`NohBoard 1.5.x`）、自定义窗口标题；
- 键盘/样式/类别等用户数据名称；
- 键名（`ScrollLock`、`Caps Lock` 等）与 `NohBoard` 日志文件内容。

## 验证

- 构建：`dotnet build NohBoard\NohBoard.sln -c Debug`。
- 手动验证：右键主窗口查看菜单，依次打开“加载键盘”“设置”等对话框。
- 静态审计脚本：`artifacts/i18n-audit.py`（`artifacts/` 已在 `.gitignore` 中）会扫描词典、所有
  `Loc.T` / `Loc.Format` 调用和设计器里的文本赋值，列出缺失或重复的 key。新增界面文本后建议跑一次。
- UI 截图验证脚本见 `artifacts/` 下的测试脚本（同样不纳入版本库）。
